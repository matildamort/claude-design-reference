# Claude Design Reference

This repository is a curated collection of visual examples produced for Rous County Council.

Its purpose is to provide Claude with reference material when creating new training materials, communications, presentations, diagrams and other visual content.

## How to use this repository

Use the examples in this repository to understand the preferred visual style and practical application of the Rous County Council brand.

Reference these examples for:

- Layout and composition
- Information hierarchy
- Typography
- Spacing and use of white space
- Colour application
- Use of imagery and graphics
- Diagrams and process visualisation
- Training and instructional design
- Internal communications
- Presentation design

These examples are intended as visual and creative references, not as mandatory templates. Do not reproduce an existing design verbatim unless specifically requested.

## Brand guidelines and official assets

The official Rous County Council Brand Guidelines and brand assets are maintained in SharePoint and are the authoritative source for brand requirements.

Before undertaking design work:

1. Locate and reference the current Rous County Council Brand Guidelines in SharePoint.
2. Locate official logo assets in SharePoint and use the appropriate approved logo variation for the design.
3. Use official brand assets from SharePoint wherever available rather than extracting logos or other brand elements from examples in this repository.
4. Use this repository to understand how the brand has been applied in practice and the visual style preferred for different types of content.
5. Where an example in this repository conflicts with the current Brand Guidelines, the Brand Guidelines take precedence.

## Repository structure

### Training Materials
Examples of quick reference guides, system guides, instructional materials, training resources and other learning content.

### Communications
Examples of project communications, staff updates, posters, announcements, campaign materials and other internal communications.

### Presentations
Examples of presentation and slide design, including project, workshop and organisational presentations.


## Important

Not every historical example in this repository represents a current or mandatory standard.

Use judgement when selecting references and prioritise examples that are most relevant to the type of content being created.

Always follow the current Brand Guidelines and use current official brand assets from SharePoint where available.
